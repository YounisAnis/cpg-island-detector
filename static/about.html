Method & limits

Follow a submitted DNA sequence from its first window to its predicted CpG island boundaries.

From sequence to island

Read each record

Submit plain DNA or FASTA. The detector scans each record independently, along the strand you supply.

Scan full windows

The scan advances in overlapping windows and skips windows with too many ambiguous bases.

Score each window

Compact LightGBM uses dinucleotide and trinucleotide frequencies, GC content and the observed-to-expected CpG ratio. The model score determines whether a window is a hit.

Call island regions

The scan groups nearby hits, takes the centres of the first and last hit windows as boundaries and applies a minimum region length.

How to use the detector

What is a CpG?

A CpG is a cytosine (C) immediately followed by a guanine (G) on the same DNA strand. The detector scores patterns across whole windows of sequence and reports islands where nearby hit windows form a qualifying region.

Which example should I start with?

Select the chromosome 21, 100 kb example and run detection. Select a reported region to see it on the track. The two 200 bp examples each illustrate a single window score.

How are ambiguous bases handled?

The detector accepts ASCII letters in either case. It treats letters other than A, C, G and T as ambiguous. Within eligible windows, only unambiguous di- and trinucleotides contribute to their frequency counts. The denominator includes all possible starting positions for that word length.

Why can a high score yield no island?

The score applies to one window. A region needs hit windows whose centres span the minimum region length. A single hit has no centre-to-centre span. Region mean and maximum scores summarize only the hit windows in that region.

What do the coordinates refer to?

Positions start at zero in each submitted record. The start is included and the end is excluded. FASTA headers label records. The detector does not align input to a genome.

What are the submission limits?

The application processes submitted sequences in server memory. Its application code does not write sequence text to logs. The first request may take longer while a sleeping instance starts.

What the benchmark supports

The study compared predicted regions with the UCSC cpgIslandExt annotation on human hg38. Strict region F1 favoured Compact LightGBM, the live detector. The neural model recovered more short reference islands. Reported boundary errors apply to predictions paired with an annotated region.

A window score is a model output. The study reports neural dense-scan calibration in Supplement S5. It provides no such calibration for Compact LightGBM. An uploaded sequence alone supplies no reference labels for measuring accuracy or DNA methylation data.

Performance on other species or assemblies remains unvalidated. Scanning the reverse complement can give different predictions. The study did not establish test-set independence during development, and the training details for the main neural checkpoint are incomplete.

For research use only. Predictions depend on the training data and do not provide clinical advice.
