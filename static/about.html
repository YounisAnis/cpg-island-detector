Method & limits

Research use only. Medical diagnosis, treatment and clinical decisions are outside this tool’s scope.

From DNA to regions

This model processes overlapping di- and trinucleotides, GC content and observed-to-expected values of CpG islands. Everything except adenine, cytosine, guanine and thymine nucleotides is considered an unknown letter. Such words are removed from the numerator, but the denominator considers everything.

Forward references sequences only are scanned. Output positions are 0-based and half open according to each record's reference. Average and maximal score values are determined by windows from hit regions.

Score value is a raw output of the model and not a probability value.

What the benchmark supports

Selection of the model was done using UCSC hg38 and cpgIslandExt Annotation. Threshold selected was tested on Human Sequence. Unvalidation of performance in any other species or genome assemblies exists. Input in reverse complement may produce different results.

Strict F1 Score favored the Compact LightGBM model. Neural model detected more short reference islands. Errors in boundary on the Results webpage refer to matches of detected predictions with the reference. Pasted sequences have no predicted coordinates.

Independence of the test set during development was not shown. Training procedures for the main neural checkpoint are described insufficiently. Calibration of neural dense-scan is provided in Supplement S5. Calibration of the compact LightGBM dense-scan has not been published.

Request limits & privacy

Processing is done on sequences using memory. Logs from applications do not contain any sequences and use identifiers only. Waiting for free instance could be observed during requests.
